# Data governance

Publicly accessible ≠ free to use.

## Required on every dataset card

- source, consent, license, language, geography
- collection method, annotation method, quality notes
- restrictions, version, removal / takedown path
- compensation and community benefit where people contributed labor

## Residency and privacy

Prefer in-region processing for production speech and personal data. Do not put private corpora in Git.

## Process

Takedown requests: info@adara.ai. Log provenance in `adara-datasets`, not in application repos.
