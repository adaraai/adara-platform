# Contributing to adara-platform

## Branching

- `main` — protected default
- `feature/<name>`
- `fix/<name>`
- `research/<name>`
- `infra/<name>`

Use pull requests. CI must pass before merge.

## Commits

[Conventional Commits](https://www.conventionalcommits.org/):

```
feat(speech): add language detection interface
fix(api): validate context requests
docs(evals): document benchmark methodology
research(codeswitch): add Twi-English fixture
infra(api): add staging workflow
```

## Local setup

See this repository's README. Do not introduce production dependencies from research notebooks.
